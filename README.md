# ComicReleaseManager public app page

楽天Web Service等のアプリ登録時に提示するための、最小限の公開説明ページです。

## GitHub Pagesで公開する手順

1. Settings → Pages → Build and deployment
2. Source を `Deploy from a branch`
3. Branch を `main`、Folder を `/(root)` に設定

公開URL:
`https://haniwa888.github.io/comic-release-manager-site/`

この公開リポジトリには、アプリ本体のソースコード・APIキー・Access Key等の認証情報を置かないでください。
